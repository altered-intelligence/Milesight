## Decisions made (to be written up as ADRs 009–015)
- 009 Canonical SI units in storage and API; clients localize (Tesla reports miles).
- 010 Simulator transport for development/demos and seeded history.
- 011 Plain lat/lon columns, no PostGIS (the compose Timescale image lacks PostGIS; the
  original schema used `GEOGRAPHY` and would not have applied).
- 012 TimescaleDB optional: migration 0002 enables hypertable/compression/retention only
  when the extension is preloaded; vanilla Postgres works for dev/CI.
- 013 Cost-aware ingestion: Fleet API bills per call and polling `vehicle_data` costs far
  more than streaming; conservative cadence, let cars sleep, never wake implicitly.
- 014 Own sessions: 15-min HS256 JWT + rotating hashed refresh tokens with reuse detection;
  Tesla tokens AES-256-GCM encrypted, bound to user id.
- 015 Defer Redis: in-process workers until horizontal scaling is needed.
